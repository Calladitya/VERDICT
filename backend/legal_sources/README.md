# legal_sources  (for "Sourced answer")

Put official law texts here as plain .txt files. The app reads them automatically (no restart needed after adding files;
the index rebuilds when files change).

## File format
First two lines are optional but recommended:

    TITLE: Consumer Protection Act, 2019
    URL: https://www.indiacode.nic.in/

    1. Short title and commencement.- ...
    2. Definitions.- ...
    69. Limitation period.- ...

- A line that starts with a section number and a dot ("69. Limitation period...") starts a new section chunk.
- Where to get texts: indiacode.nic.in (search the Act, open the PDF, copy the text into a .txt file).
- Suggested first set: Consumer Protection Act 2019, RTI Act 2005, BNS 2023, BNSS 2023, BSA 2023, Legal Services Authorities Act 1987.
- Keep the TITLE exact; it is what users see as the source name.

Answers are only as good as the texts you load. Always keep the official URL in the file header.
